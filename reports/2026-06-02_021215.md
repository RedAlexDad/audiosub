## What was changed
- **runtime Vosk**: vosk crate заменён на vosk_dl — libvosk.so загружается через libloading при запуске
- **Cargo.toml**: удалён vosk feature/dep, добавлены libloading + serde_json
- **Один бинарник**: vosk и whisper в одном файле, выбор движка — runtime
- **CI/CD упрощён**: матрица сборок сокращена до minimal/default, удалены Vosk SDK шаги
- **Dockerfile упрощён**: build без Vosk SDK, SDK только для runtime образа
- **Makefile**: убраны дублирующиеся цели (build-whisper, build-both, release-whisper, etc.)

## Как это работает
- Whisper — всегда доступен (compile-time, по умолчанию)
- Vosk — загружает libvosk.so при старте. Если .so нет — VoskEngine возвращает ошибку
- При `engine = "vosk"` в конфиге и отсутствии libvosk.so — авто-переключение на whisper
- Без `whisper` feature остаётся только Vosk (если libvosk.so есть)

## Что изменилось в бинарнике
- Раньше: два бинарника (vosk+whisper и whisper-only)
- Теперь: один бинарник — whisper встроен, vosk подключается по желанию
- Размер: ~4.3 MB (как и раньше)
