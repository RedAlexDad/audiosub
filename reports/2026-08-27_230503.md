# Report 2026-08-27_230503 MSK

## What was added
- Включён GPU-бэкенд whisper.cpp: в зависимость `whisper-rs` добавлена
  фича `cuda` (сборка GGML_CUDA=ON и линковка cuBLAS/cudart).
- В `.gitignore` добавлены `saved/` и `saved/*` — экспортируемые во время
  сессии копии субтитров не попадают в репозиторий.

## What was changed
- `Cargo.toml`: `whisper-rs` теперь имеет `features = ["default", "cuda",
  "tracing_backend"]` вместо `["default", "tracing_backend"]`.
- `.gitignore`: три строки для игнорирования `saved/`.

## Problems encountered
- CUDA 13.1 не собирался с glibc 2.43: в `/usr/include/x86_64-linux-gnu/
  bits/mathcalls.h:206` `rsqrt`/`rsqrtf` объявлены с `noexcept`, что
  конфликтует с заголовками `crt/math_functions.h` CUDA 13.1.
- Драйвер 595.84 ограничивает совместимость: CUDA 13.3 требует драйвер
  >=610.43, т.е. недоступен; подходит только CUDA 13.2.
- Runfile-инсталляторов CUDA 13.2 нет (все URL 404), сборка возможна
  только из deb-пакетов.
- Загрузка .deb c developer.download.nvidia.com зависала по HTTP/2.
- Первый `dpkg -i` прошёл в неправильном порядке зависимостей, а в наборе
  не хватало `cuda-toolkit-13-2-config-common` и `cuda-culibos-dev-13-2`.
- Бинарник `audiosub` не установлен в PATH — пользователь не смог
  выполнить `audiosub --download-model whisper:large`.

## How they were solved
- Установлен CUDA 13.2 Update 1 (11 пакетов через точечный `dpkg -i` из
  репо ubuntu2404): nvcc/crt/cudart/cudart-dev/cccl/culibos-dev/
  driver-dev/libnvvm/libnvptxcompiler + libcublas13(-dev)-cuda-13 13.2.2.2.
  В заголовках 13.2.78 подтверждён фикс `_NV_RSQRT_SPECIFIER noexcept(true)`
  (`math_functions.h:136`), тестовый `nvcc t.cu` компилируется.
- Драйвер не тронут (совместимость ≤13.2 соблюдена), apt-источники не
  менялись; `/usr/local/cuda` переведён на 13.2 через update-alternatives.
- Пакеты взяты deb/apt-путём из официального репо, минуя runfile.
- Скачивание переведено на `curl --http1.1` (HTTP/2 подвисал).
- Донастроено `dpkg --configure -a` после добавления недостающих пакетов;
  cuBLAS 13.2.2.2 прилинкован в `cuda-13.2/targets/x86_64-linux` через
  symlink'и + обновлён кэш `ldconfig`.
- Ход включённой фичи проверен на GPU: модель `ggml-small.bin` распознаёт
  в реальном времени, процесс держит ~700 MiB VRAM при util 33 %.
- Как запускать: `cargo run -- --model models/ggml-small.bin` либо
  `./target/debug/audiosub --download-model whisper:large`.
