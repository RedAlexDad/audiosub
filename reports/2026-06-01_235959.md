## Problems encountered

1. **perf_buffer_flush_500_ready_500_pending** — assertion `flushed.len() >= 100` падал: сегменты перекрывались по времени (gap 10ms < width 100ms), merge объединял их в один
2. **perf_split_segment_300s_20_words** — threshold 10000 ns слишком жёсткий для `cargo test` (debug profile); на CI может флапать
3. **cargo fmt** — код в `tests/` не проходил `cargo fmt --check`, пришлось запустить автоформатирование
4. **Receiver::clone** — `Receiver` не реализует Clone, изменил API на `Sender` + отдельные каналы

## How they were solved

1. Флаш-тест переписан: не-перекрывающиеся сегменты (width 80ms, gap 120ms), подсчитано точное число флашащихся (30 из 500 ready)
2. Пороги повышены в 2× для debug-сборки: 1000→2000 ns, 10000→20000 ns
3. `cargo fmt` запущен после всех изменений
4. WorkerHandle::spawn принимает `mpsc::Sender` вместо `Receiver`
