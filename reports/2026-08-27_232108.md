# Report 2026-08-27_232108 MSK

## What was added
- Спецификация `whisper:large` переведена на актуальную модель
  `ggml-large-v3.bin` (крупнейшая доступная в репо ggerganov/whisper.cpp).
- Параметрам `curl` добавлены `-4 --http1.1` — в этой системе обращение
  к huggingface.co без них может зависать (как и к developer.download.nvidia.com).

## What was changed
- `src/session/model.rs`:
  - URL и имя файла `whisper:large` заменены на `ggml-large-v3.bin` —
    оригинальный `ggml-large.bin` удалён с Hugging Face (404).
  - `download_whisper()`: `curl -L -o` → `curl -4 --http1.1 -L -o`.
  - `download_vosk()`: тот же набор опций для единообразия.

## Problems encountered
- Первый вариант фикса качал модель с добавленным `-C -` (докачка),
  но при уже существующем битом файле 15 байт это дало бы повреждённую
  модель (Range: bytes=15-).
- Пользователь выполнил `--model ggml-large-v3.bin.` (с точкой) — ошибка
  "Failed to create a new whisper context" оказалась вызвана неверным путём;
  без точки модель грузится.
- После загрузки контекста приложение упало на `No such device or address
  (os error 6)`: на тестовой машине нет аудиоисточника, а `--list-devices`
  требует `pactl`, который не установлен.

## How they were solved
- `-C -` убран — оставлен простой `curl -4 --http1.1 -L -o` (перезапись).
- Проблема пути объяснена пользователю, проверен запуск без точки.
- Ошибка захвата — окружение (PipeWire-Pulse без sources, нет pactl);
  на рабочей машине достаточно `--device <монитор/кабель>`.
